Overview

This project demonstrates a complete Data Analytics workflow, starting from data collection and preparation to visualization and reporting. The project involves loading a dataset using Python, performing Exploratory Data Analysis (EDA), cleaning and transforming data, running SQL queries in MySQL, creating an interactive Power BI dashboard, generating a business report, and preparing a presentation using Gamma.

The objective is to extract meaningful insights from the data and present them in a clear and business-friendly format.
